# beatlock-site

BeatLock（iOS 节拍器 App）的介绍、支持与隐私政策页，经 GitHub Pages 托管。

- 站点：<https://peterchen1997.github.io/beatlock-site/>
- 支持页（App Store Connect 的「支持 URL」）：<https://peterchen1997.github.io/beatlock-site/support.html>
- 隐私政策（App Store Connect 的「隐私政策 URL」）：<https://peterchen1997.github.io/beatlock-site/privacy.html>

主仓库是私有的 `PeterChen1997/beatlock`。这里只放对外页面，不放工程文档——
`beatlock/docs/` 里那些（spec、执行方案、踩坑记录）是内部材料，不发布。

改完直接推 `main`，GitHub Pages 会自动重建。改动如果影响到「App 会不会把数据发出去」
这类事实，记得同步改主仓库里对应的实现与说明，别让两边的说法分叉。
